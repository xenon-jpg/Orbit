# AltDeck

**Независимый менеджер аккаунтов Roblox для Windows 10/11.** React + TypeScript + Rust + Tauri 2. Русский интерфейс по умолчанию, английский переключается в настройках.

> **Статус: экспериментальная версия 0.1.0, не готовый установщик.** Исходники и браузерный демонстрационный интерфейс собраны и проверены в Linux. Нативная Windows-сборка и запуск настоящего Roblox здесь не завершены/не проверены. Не используйте эту версию как единственное хранилище важных сессий. Это не полная копия RoALT и не проект его авторов.

## Что можно посмотреть сейчас

```bash
npm ci
npm run dev
```

Откройте адрес Vite. **Браузерная версия — только демо:** вымышленные аккаунты, нарисованные сцены вместо скриншотов, фиктивные показатели и очередь. Она не открывает Roblox, не принимает настоящие cookies/webhooks и не хранит секреты. Не путайте её с рабочим Windows-клиентом.

## Сборка Windows-версии

Понадобятся Windows 10/11 x64, Node.js 22 LTS, Rust stable с целевым окружением MSVC, Visual Studio Build Tools 2022 с компонентами C++ и Windows SDK, WebView2 Runtime. Подробности и команды: [docs/BUILD_WINDOWS.md](docs/BUILD_WINDOWS.md).

```powershell
npm ci
npm run check
npm run test:e2e
rustup target add x86_64-pc-windows-msvc
cargo test --manifest-path src-tauri/Cargo.toml --lib
npm run desktop:build
```

Последняя команда собирает NSIS-установщик. **Успешная сборка не означает, что запуск Roblox проверен.** Перед использованием пройдите [docs/WINDOWS_ACCEPTANCE.md](docs/WINDOWS_ACCEPTANCE.md). Подпись установщика сертификатом не выполнялась.

## Реализованные части

- Локальное шифрованное хранилище: AES-256-GCM, отдельный случайный ключ данных, обёртка DPAPI или Argon2id + мастер-пароль; код восстановления, автоблокировка, резервная копия.
- Окно официального входа Roblox с отдельным каталогом WebView2, ручной импорт своей сессии, проверка и обновление аккаунтов; повторное подтверждение при показе/копировании cookie.
- Псевдонимы, заметки, избранное, Robux, присутствие, друзья, подписчики, Premium и группы — через API Roblox, если он доступен.
- Запуск по Place ID, ссылке игры, Job ID, приглашению частного сервера, профилю или `@username`; пакетная очередь, задержка, выбор общего сервера, следование за первым аккаунтом.
- Нативные механизмы multi-instance, защита общих файлов входа, проверка подписи установленного Roblox, ограничение CPU через Job Object, управление окнами, ограниченный предпросмотр PrintWindow.
- Автопереподключение/перезапуск, ограничитель повторных попыток, контроль зависания/памяти, opt-in anti-AFK, уведомление об обновлении Roblox без скачивания установщика.
- Профили производительности, ограниченный набор FFlags, FPS, CPU, маленькие окна, working-set trim; импорт/экспорт профилей.
- Браузер серверов, Discord webhook, диагностика без секретов, темы, фоновое изображение, RU/EN.

Фактическая работоспособность каждого нативного пункта зависит от проверки в Windows. Матрица: [docs/STATUS.md](docs/STATUS.md).

## Важные ограничения

- Multi-instance не поддерживается Roblox и может перестать работать после любого обновления. AltDeck не обходит античит, аппаратную привязку сессий или проверку браузера.
- Предпросмотр — примерно 1 кадр/с через PrintWindow, не полноценный захват DirectX. Свёрнутые/неподдерживаемые окна могут не показываться.
- GPU по процессам, автоматическое обновление самой AltDeck, разрешение новых share-ссылок и полная совместимость с RoALT **не реализованы**.
- Флаги графики экспериментальны. Ограничения CPU и восстановление после повторного входа в Windows требуют отдельной проверки.
- Диагностический журнал хранится в памяти до 200 событий и очищается при перезапуске. Экспортируйте его при необходимости.
- Используйте только свои аккаунты. Автоматизация и одновременные клиенты могут нарушать правила игры/платформы; риск блокировки нельзя исключить.


Результаты текущей среды: [docs/VERIFICATION.md](docs/VERIFICATION.md). CI дополнительно запускает Windows-сборку после публикации репозитория; локального подтверждения Windows-сборки пока нет.

## GitHub

Проект подготовлен для публикации, но **в GitHub из этого чата ничего не загружено**: подключение GitHub недоступно. Не отправляйте токен GitHub в чат. Создайте пустой репозиторий и выполните инструкции в [docs/PUBLISH_GITHUB.md](docs/PUBLISH_GITHUB.md), либо запустите `scripts/publish-github.ps1` после входа в GitHub CLI. Скрипт не создаёт фиктивный remote и не содержит токенов.

## Данные и безопасность

В Windows данные находятся в `%LOCALAPPDATA%\dev.altdeck.desktop`. Не публикуйте `vault.json`, `.altdeck`, cookies, authentication tickets, профили WebView2 и логи запуска. Они исключены из архива исходников. Браузерное демо использует только не-секретный ключ `altdeck-demo-v1` в localStorage.
