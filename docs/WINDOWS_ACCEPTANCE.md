# Приёмочные испытания Windows

Используйте отдельную Windows-учётную запись/VM и **свои тестовые аккаунты**. Не передавайте cookies разработчику. Сначала сделайте резервную копию важных данных. Не начинайте с ценных аккаунтов.

## Сборка и установка
- [ ] `cargo check --lib`, Rust tests, frontend build/tests проходят на Windows.
- [ ] NSIS устанавливается обычным пользователем и запускается без elevation.
- [ ] Повторный запуск фокусирует существующее окно, не создаёт второй менеджер.
- [ ] Удаление приложения не удаляет пользовательские документы вне его каталога.

## Хранилище
- [ ] Новый vault с DPAPI; закрытие/повторное открытие сохраняет аккаунты.
- [ ] Мастер-пароль ≥12 байт; неверный пароль не открывает данные.
- [ ] Код восстановления меняет пароль и аннулирует прежний код.
- [ ] Файл vault и backup не содержат cookie в открытом виде.
- [ ] DPAPI backup не открывается другим пользователем Windows; password backup открывается с паролем.
- [ ] Автоблокировка срабатывает при открытой вкладке и фоновой очереди; polling не продлевает её.
- [ ] Показ/копирование cookie требует повторного пароля/Hello; буфер очищается штатным механизмом.
- [ ] Повреждённый vault не перезаписывается новым пустым хранилищем.

## Вход и API
- [ ] Окно входа использует отдельный профиль; отмена/таймаут удаляют его.
- [ ] 2FA проходит в официальном окне; AltDeck не запрашивает пароль Roblox.
- [ ] Импорт своей сессии, повторный импорт того же аккаунта, неверный и отозванный cookie.
- [ ] Ротация `.ROBLOSECURITY` при API-запросе не теряет новую сессию.
- [ ] HBA/challenge даёт понятный отказ, не обход защиты.
- [ ] Robux/presence/groups/friends и rate limit отображаются корректно.

## Процессы и запуск
- [ ] Действительный Roblox запускается; изменённый/неподписанный executable отклоняется.
- [ ] Обычный уже открытый Roblox обнаруживается; tray-process не считается игровым клиентом.
- [ ] Два клиента, пакет из трёх, задержка и отмена во время задержки.
- [ ] Общий сервер имеет достаточно мест; private invitation link и accessCode не путаются.
- [ ] Follow учитывает приватность; недоступный сервер не создаёт ложный успех.
- [ ] Завершение клиента не затрагивает чужой процесс с повторно использованным PID.
- [ ] Закрытие приложения освобождает singleton и файловые блокировки.
- [ ] Восстановление после перезапуска приложения не управляет чужими окнами.

## Производительность и автоматизация
- [ ] CPU cap и fair sharing действительно ограничивают нагрузку; после restart/re-attach поведение задокументировано.
- [ ] FPS/FFlags применяются и восстанавливаются; чужие изменения файла сохраняются.
- [ ] Аварийное завершение с последующим восстановлением FFlags.
- [ ] Маленькие окна, tile на одном/двух мониторах и разных DPI.
- [ ] PrintWindow не показывает чужое окно; minimized/game DirectX limitations понятны.
- [ ] Rejoin, crash, frozen и memory restart; breaker прекращает бесконечный цикл.
- [ ] Anti-AFK выключен по умолчанию, не отправляет ввод в другое приложение и не мешает активному пользователю.
- [ ] Уведомление об обновлении Roblox не скачивает/не запускает сторонний updater.

## Сеть и диагностика
- [ ] Webhook принимает только официальный Discord HTTPS; mentions отключены.
- [ ] Ошибки HTTP/сети не раскрывают cookie, ticket, webhook token или тело ответа.
- [ ] Экспорт диагностики не содержит секретов; журнал очищается при перезапуске.
- [ ] Проверить отсутствие неожиданных исходящих запросов, кроме Roblox/rbxcdn и настроенного Discord.

Результат каждого пункта записывайте с версией Windows, версией Roblox, датой и(redacted)логом. Пока пункты не пройдены, версия остаётся experimental.
