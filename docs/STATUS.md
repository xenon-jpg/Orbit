## Известные технические ограничения

- После перезапуска приложения клиенты восстанавливаются по PID + времени создания и пути исполняемого файла. Job Object не восстанавливается: прежний лимит CPU может не действовать до нового запуска клиента. Защита общих файлов также должна быть проверена после восстановления.
- Один общий XML-файл FPS ограничивает независимость per-account FPS. Значение применяется перед каждым запуском, но уже работающий клиент может не перечитать его.
- Восстановленный клиент не имеет прежнего in-memory счётчика перезапусков. Ограничитель начинает новый отсчёт после перезапуска приложения.
- Восстановление FFlags выполняется только при точном совпадении файла с последней записью AltDeck; чужие изменения не перезаписываются. Это может оставить часть настроек до ручного удаления.
- Очередь останавливается на первой ошибке. Уже запущенные клиенты не закрываются автоматически при отмене оставшейся очереди.
- Вебхук содержит тип события, а не полный журнал. Диагностика не является постоянной базой данных.
- Браузерный адаптер не является средством проверки безопасности Windows-хранилища.

Следующий этап: исправить ошибки первой Windows-сборки, пройти приёмочный чек-лист, затем стабилизировать восстановление и только после этого выпускать установщик как рабочий релиз.
